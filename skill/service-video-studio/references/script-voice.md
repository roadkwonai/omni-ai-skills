# 대본 · 음성 · 자막

## 대본

- 첫 5초에 '왜 봐야 하는지'(문제)를, 15초 안에 '무엇인지'를 말한다. 마지막은 한 문장 요약 + 주소.
- 문장은 -ㅂ니다체, 한 문장 3~10초(60자 안팎). 14초를 넘으면 나눈다. 나열은 네 개까지.
- 실제 화면에 나오는 낱말을 쓴다. 대본의 '재진입'이 화면에는 '최근 분봉 상승 아님'이어서 이름표와 어긋난 적이 있다. 촬영할 화면을 보고 쓴다.
- 주장마다 `fact`: 문서 절, 화면, 논문과 연도. 조건을 줄이면서 뜻이 바뀌지 않았는지 본다("내린 종목보다"를 빼면 비교 대상이 사라진다 → 화면 글자로 보완).
- 과장·수익 보장·권유·최고/유일 같은 말은 `banned`에 넣는다. 투자·의료·법률은 면책 문구 장면을 둔다. 한 사례를 일반 효과처럼 말하지 않는다.
- 날짜에 묶인 문장('지금은 조정 국면')은 표시해 두고 다시 만들 때 고친다.

## 읽기(tts)

`review_script.py`가 빈 `tts`를 채운다. 숫자·영어·기호를 모두 한글로 바꾸는데, TTS가 숫자를 제멋대로 읽는 것을 막고 자막과 어절 수를 맞추기 위해서다. 어절 수가 다르면 자막 시간이 밀린다.

- 영어 이름은 `script.json`의 `reading`에 한글 읽기를 넣는다(없으면 멈춘다).
- 고유어/한자어가 헷갈리는 단위(번·대·장)와 뜻에 따라 다른 읽기는 `tts`를 손으로 고친다. 손으로 고친 값은 덮어쓰지 않는다. 자막(`cap`)을 고쳤으면 `tts`를 비우고 다시 돌린다.

## 로컬 음성 (Drama 3 · S2 Pro)

`voice_opts`는 전체 기본값이고 문장의 `opts`가 덮는다. 바뀐 문장만 다시 만든다. 모든 문장이 `assets/voice/ref.wav` 한 소리를 참조하므로 목소리가 문장마다 바뀌지 않는다.

```json
"voice_engine": "drama-3",
"voice_opts": { "design": {"gender": "female", "age": "young", "tones": ["clear"], "energy": "confident", "note": "또박또박한 안내 목소리", "scene": "quiet studio", "seed": 3},
                "style": "narration", "speed": 1.15 },
"lines": [ { "id": "S05", "cap": "한 달 만에 줄었습니다.", "tts": "<emphasis>한 달 만에</emphasis> [pause] 줄었습니다.", "opts": {"style_note": "calm but proud", "seconds": 4} } ]
```

| 옵션 | drama-3 | s2-pro |
| --- | --- | --- |
| `design` 성별·나이·음높이·음색(최대 3)·분위기·설명·장면·시드 | 씀 | Drama 3가 만든 소리를 참조(말투 변화는 약함) |
| `ref` {audio, text} 내 목소리·허락받은 목소리(60초 이하, 실제 읽은 글과 함께) | 씀 | 씀 |
| `style` 18종 · `style_note` 직접 쓴 말투 | 씀 | 참조의 말투를 거의 그대로 따름 |
| `seconds` 목표 길이 | 씀(글자당 0.2초보다 짧으면 거절) | 못 씀 |
| 대사 안 `[pause]` 등 · `<emphasis>말</emphasis>` 등 | 20종 · 13종 | 확인된 6종 · 못 씀 |
| `speed` `semitones` `normalize` `temperature` `top_p` `top_k` `seed` | 씀 | 씀 |

- 새 프로젝트의 기본 목소리는 `install.py --voice <파일> "<읽은 말>" ["<이름·출처>"]`로 저장한 것이고(없으면 기본 설계), 프로젝트 안 `assets/voice/`에 복사해 참조한다. 설계로 바꾸려면 `voice_opts`에서 `ref`를 지우고 `design`을 넣는다.
- 지시 표시는 자막과 어절 수에 들어가지 않는다. 여러 어절을 감싸도 된다.
- 길이를 **줄일** 때는 `seconds`가 아니라 `speed`를 쓴다(짧게 시키면 뒷말이 빠진다). 같은 설정과 시드는 같은 소리를 만든다. 다시 만들려면 `opts.seed`를 바꾼다.
- 속도: M1 Ultra에서 음성 1초에 Drama 3 0.7~1.1초, S2 Pro 1.2~1.3초 + 처음 모델 올리기. Drama 3는 메모리 22GB를 쓰니 여유를 보고 돌리고, 다른 로컬 모델과 동시에 돌리지 않는다.
- 앞뒤 무음은 자동으로 다듬고(대본에 적은 쉼은 남김), 로컬 음성은 작게 나와 `timeline.py`가 내레이션 전체 크기를 기준작에 맞춘다(문장끼리의 세기 차이는 남김).
- 목소리를 참조할 때 실존 인물을 동의 없이 흉내 내지 않는다. 결과를 다른 음성 모델 학습에 쓰지 않는다. 합성 음성이므로 게시할 때 AI 사용을 표시한다.

## Fish Audio API

- `POST https://api.fish.audio/v1/tts`, 무료 모델 `s2.1-pro-free`, `language: ko`, `normalize: false`. 유료 `s2.1-pro`와 Fish ASR은 충전금이 없으면 402다. 429·503은 기다렸다 다시 한다(스크립트가 한다).
- 기본 목소리 `ca3becd0e8014733b0405c3ad9ffe50e`(차분한 중년 남성, 사용자가 고른 것). 바꿀 때는 한 문장 샘플 2~3개를 먼저 들려준다. 실존 인물 흉내 목소리는 쓰지 않는다.
- 키는 `.env`나 환경변수에서만 읽고 출력하지 않는다. 대본 글이 외부 서비스로 나간다는 것을 처음 한 번 알린다.
- 대안: 위 로컬 음성, 본인 녹음(포트폴리오에는 이쪽이 더 믿음이 간다 → `assets/vo_raw/<ID>.mp3`에 넣고 S3부터).

## 시간표

`speed` 1.1(atempo, 음높이 유지), `gap` 1.0, `part_gap` 1.5, `lead` 0.6, `tail` 2.5. 길이를 줄여야 하면 순서대로: 문장 줄이기 → 파트 합치기 → `gap` 0.8. 배속은 1.15를 넘기지 않는다.

## 단어 시각과 자막

- 받아쓰기는 반드시 `--model small --language ko`. 기본 모델은 한국어를 영어로 번역한다.
- 받아 적은 글자가 아니라 시간만 쓰고 글자는 대본에서 온다. `words.py`가 글자 수 비율 70~130%를 벗어난 문장을 알려 주면 음성을 들어 본다(발음 누락·반복).
- 자막: 아래 80px, 46px, 최대 6어절, 문장 끝·쉼표(3어절 이상)·0.35초 쉼에서 끊고, 한 어절만 남는 줄은 만들지 않는다. 현재 단어에 강조색 상자.
- `theme`: `[["P1", 0, "light"], ["P1", 4.4, "dark"]]`(파트, 장면 안 초, 밝기). 밝은 녹화 위는 light. 바뀌는 순간은 **그 구간 첫 단어보다 0.3초 이상 앞**에 둔다. 자막 줄의 밝기는 줄이 시작할 때 정해진다.
- 같은 문장을 큰 글자와 자막으로 동시에 띄우지 않는다. 큰 글자는 핵심 낱말만.
- 흰 글자/주황 상자 대비 경고(`contrast_aa_failure`)는 의도한 조합이라 둔다.
