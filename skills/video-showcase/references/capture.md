# 녹화와 가림

## 가림 목록부터

PLAN.md에 세 칸 표로 적는다: 화면에 나오는 것 | 보임/가림 | 이유. 다음을 하나씩 확인한다.

- 돈: 금액, 수량, 단가. **여기서 끝내지 않는다** → 수익률, 승률, 체결·매도 건수, 거래 시각, 잔고 비율, 한도 값도 같은 사실을 드러낸다.
- 사람: 이름, 연락처, 이메일, 프로필 사진, 채팅 상대, 서버·채널 이름
- 시스템: 계정명이 든 경로, 토큰·웹훅 주소, 내부 URL, 계좌·주문 번호, 환경변수 화면
- 이름표: '실계좌 2 · 전략' 같은 라벨은 금액이 없어도 무엇을 하는지 드러낸다. 보여도 되는지 묻는다.
- 이미 공개된 스크린샷·README 이미지도 다시 본다(가림 없이 공개돼 있던 적이 있다).

기본은 `rest: "hide"`(모르면 가림)다. 보여 줄 것만 `open`으로 연다. 공개 시세처럼 모두 공개인 화면에서만 `rest: "show"` + `secret`을 쓴다.

## mask.js 설정

```js
// capture/mask.config.json 의 mask
{ "rest": "hide", "secret": "실계좌|합계|운용금", "open": "모의|가상|지수", "card": ".sc" }            // 모르면 가림, 보여 줄 것만 연다
{ "rest": "show", "secret": "매출|원장 전용", "blurSel": "td:nth-child(2),td:nth-child(3)" }        // 대부분 공개인 화면: 비밀 카드 + 이름·연락처 열만
```

행에 공개 값(시각)과 비밀 값(연락처)이 섞였으면 `secret`에 행 글자를 넣지 말고 `blurSel`로 그 열만 흐린다. 행 전체가 비밀이면 `secret`이 맞다.

- 판정 단위: 글자가 든 **카드 · 표 행 · 문단** 중 하나라도 `secret`이면 그 안의 값(`value`, 기본 숫자)을 모두 흐린다. `secret`이 `open`보다 우선한다.
- `value`에 걸리지 않는 값(사람 이름 등)은 `blurSel`로 선택자를 준다. 이름까지 감출 표는 열을 통째로 준다.
- 실제 화면에서 `document.querySelectorAll` 로 카드 선택자를 먼저 찾는다.
- **canvas로 그린 표**(Streamlit `st.dataframe` 등)는 글자가 없어 CSS로 안 가려진다. 숨은 접근성 행(`role="row"`)을 읽어 덮는데, 머리·행 높이를 화면에서 재서 `rowH`로 준다. 35px로 어림했다가 한 행이 새어 나갔고 실제는 32px였다. 안에서 스크롤되는 표는 다시 확인한다.
- SVG 도식 속 값, 슬라이더 숫자, 입력칸 값, `title`·툴팁도 새는 곳이다. 툴팁은 커서를 올리지 않는 것으로 막는다.
- 흐린 값은 원본 크기에서 **읽어 보려고 해 본다.** 큰 글자일수록 잘 읽힌다. 값의 길이·색(손익 빨강·파랑)도 단서다. 알려지면 안 되는 카드는 흐리지 말고 `hideSel`로 없애거나 찍지 않는다.
- 가림은 녹화하는 브라우저에만 넣는다. 앱 코드·설정·데이터는 바꾸지 않는다.
- 화면이 다시 그려질 때(탭·팝업)마다 `mask()`를 다시 부른다(`press()`가 한다). 팝업은 **열리는 중간 프레임**도 본다.

## 녹화 방법

ego-browser + CDP `Page.captureScreenshot` 연속 캡처가 기본이다. 1920×1080, 약 14~17fps, `record.py`가 프레임 시각대로 30fps mp4로 만든다. 같은 장면을 스크립트로 되풀이할 수 있고 가림을 넣기 쉽다. 마우스로 하는 앱이나 터미널처럼 브라우저 밖 장면은 Screen Studio·OBS로 손으로 찍는다.

- 한 컷은 3~8초. 길게 찍어 잘라 쓰지 말고, 말할 문장 순서대로 움직이게 쓴다.
- 커서는 `move()`(CSS 전환이라 부드럽다), 클릭은 강조색 원. 화면이 다시 그려지는 몇 초는 `paused`로 녹화를 멈춘다 → 점프 컷.
- 요소는 글자가 **정확히 같은 보이는 것**으로 찾는다. 앞부분만 같은 탭, 사이드바의 같은 이름 버튼을 누른 적이 있다.
- 스크롤은 본문 스크롤 영역을 골라서 한다(사이드바가 잡힌 적이 있다). 탭을 바꾼 뒤에는 맨 위로 돌린다.
- 작은 라벨은 장면의 `zoom(x, y, 1.6)`으로 촬영에서 확대한다(페이지 전체가 커지므로 옆이 잘린다). 화면 전체가 작으면 확대 대신 `css`를 줄여 다시 찍는다.
- `press()`는 누른 순간을 `누름:<글자>`로 자동 표시한다. 녹화를 말에 맞추려면 이 시각과 단어 +초의 차이로 `data-media-start`를 정한다(다시 찍지 않아도 된다).
- `mark("이름")`은 멈춘 구간을 뺀 **클립 안 시각**으로 출력된다 → `data-media-start`에 쓴다.
- 화면에 보이기만 해도 오해를 살 버튼(전송·주문)은 `hideSel`로 숨길 수 있다.
- 누르지 않을 버튼 목록(저장·전송·결제·주문·스위치·삭제)을 스크립트 첫 줄에 적는다.
- 운영 중인 서비스라면 사용자가 쓰는 포트·세션이 아닌 확인용 인스턴스를 쓴다. API 한도를 같이 쓰면 자동 갱신을 끄거나 한가한 시간에 찍는다.

## 정지 화면

장면 스크립트에서 `still("이름")`을 부르면 가림된 화면이 커서 없이 `assets/img/`와 `remotion/public/`에 저장되고, `spot("이름", 선택자, "글자")`가 그 화면의 칸 좌표를 재서 출력한다(눈대중하지 않는다). 이미 찍은 영상에서 뽑을 때는 `ffmpeg -ss T -i x.mp4 -frames:v 1 -q:v 2`. 가림이 된 것만 이 두 폴더에 둔다.

## 찍은 뒤 확인

1. 팝업·표·도식이 나오는 프레임을 원본 크기로 열어 본다. 가림 목록을 한 줄씩 짚는다.
2. 화면의 날짜·상태가 대본과 맞는지 본다. 다른 날 다시 찍으면 숫자가 바뀐다.
3. 다시 찍은 이유와 찾은 누락을 PLAN.md 이력에 남긴다.
