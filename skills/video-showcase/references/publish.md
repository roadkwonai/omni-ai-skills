# 게시 · 썸네일 · 소개 페이지

공개 게시, 채널 설정 변경, 커밋, 배포는 각각 사용자 승인이 있어야 한다. 전화·비밀번호·인증번호는 사용자가 직접 넣는다.

## 올리기 전 초안 파일(`upload-draft.md`)

제목(60자 안, 무엇을 하는지 + 이름), 공개 범위, 카테고리, 아동용 여부, AI 사용 표시(합성 음성이면 '예'), 로컬 음성이면 설명 끝에 `Built with Fish Audio`(S2 Pro 음성은 비상업 영상에만), 설명, 태그 10~12개.

설명 순서: 두 줄 요약 + 저장소 링크 → 챕터(0:00부터, `timeline.json`의 파트 `scene_start`를 반올림) → 무엇을 하나요 → 만든 것 → 유의사항. 챕터는 3개 이상, 각 10초 이상.

## 썸네일

1. **문구 후보 6~8개부터** 보여 준다: 서비스의 매력·핵심 기능을 말하는 문구("단타는 Jev가, 장기투자는 거장 원칙으로"가 골라졌다). 만든 사람 이야기("혼자 만든")나 낚시 문구는 거절됐다.
2. 고른 문구로 HTML 1280×720 합성: 왼쪽 로고 + 두 줄 제목(72px 900, 강조 한 단어) + 한 줄 설명 + 칩, 오른쪽에 실제 가림 화면을 기울여(`perspective(1400px) rotateY(-16deg)`) 겹친다. 생성 이미지보다 실제 화면이 낫다.
3. 160px로 줄여도 읽히는지 본다. 2MB 이하 png/jpg.

## 유튜브 Studio(브라우저 조작)

- 먼저 로그인 계정 이메일과 채널 이름을 화면에서 읽어 사용자에게 말한다. 프로필을 짐작하지 않는다.
- Aside CLI REPL은 실행이 끝나면 탭이 닫히고 세션 폴더 파일만 읽는다. 파일은 `127.0.0.1` 임시 서버로 받게 한다. contenteditable 칸은 키보드 입력(`insertText`)으로 넣는다.
- 업로드 첫 시도에서 제목·설명이 사라진 적이 있다. 초안(Draft)을 다시 열어 넣고, 저장 뒤 다시 읽어 확인한다.
- 맞춤 썸네일은 전화번호 인증이 먼저다(사용자가 함). 언어 칸은 자동 선택이 실패한 적이 있다 → 확인 후 비었으면 알린다.
- 유튜브 자동 자막이 구운 자막과 겹칠 수 있다. 끄는지 묻는다.
- 끝나면 공개 페이지를 로그아웃 상태로 열어 제목·설명·썸네일·공개 범위를 확인한다. 실제로 확인한 것만 완료라고 말한다.

제목·설명·챕터를 더 다듬으려면 `yt-seo`·`yt-package`·`yt-chapters` 스킬을 쓴다.

## README·소개 페이지

README: 위쪽 링크 + 클릭되는 썸네일(webp/jpg) + 챕터 표. 웹: 눌러야 불러오는 `youtube-nocookie.com` iframe, 썸네일 `alt`, 챕터 버튼(`?start=초`). 커밋·배포 전 그 저장소의 릴리스 규칙(버전 번호를 누가 정하는지, 푸시 대상)을 읽는다. 다른 세션의 변경이 섞여 있으면 내가 바꾼 파일만 커밋한다.

## 채널을 새로 꾸밀 때

채널은 서비스 하나가 아니라 만든 사람의 주제로 잡는다(이름·설명에 다른 프로젝트 포함). 배너 2560×1440(가운데 1546×423 안전 영역), 프로필 800×800, 워터마크 투명 png. 이미지는 gpt-image 스킬, 글자는 HTML 합성으로 넣는다(생성 이미지 속 한글은 깨진다).
